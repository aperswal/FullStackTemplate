# Messages

This folder is the source of truth for localized user-facing strings.

Do not hardcode production UI copy in components when the lint rules expect message keys. Add or update message keys here and keep names stable, descriptive, and grouped by product area.

Messages are interface copy. Read `CLAUDE FILES/ux.md` for form labels, errors, empty states, and onboarding copy; read the writing pipeline when revising marketing or transactional text.

Keep strings clear, actionable, and free of implementation details. Error messages should say what happened, who can fix it, and what the user can do next when that is safe to reveal.
